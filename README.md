## ✨ Features

### 📝 Editor & Workspace
| Feature | Description |
|---------|-------------|
| 🗂️ **Multi-Tab Interface** | Work on multiple files simultaneously with tabbed browsing |
| 🔢 **Line Numbers** | Real-time synchronized line numbering with dynamic width |
| 🎯 **Auto-Complete** | Intelligent code completion powered by **Jedi** (`Ctrl+Space`) |
| 🌍 **Bilingual UI** | Full support for **English** & **Arabic** (Cairo font) |
| 💾 **Auto-Save Detection** | Unsaved changes indicator with `*` on tab title |
| ⚡ **Keyboard Shortcuts** | Full shortcut suite for power users |

### 🔍 Code Intelligence
| Feature | Description |
|---------|-------------|
| 🔬 **AST Analysis** | Deep code analysis to detect all imported libraries |
| 📦 **Library Detection** | Automatically distinguishes built-in vs external packages |
| ⬇️ **One-Click Install** | Install missing dependencies directly from the UI |
| 🎨 **Black Formatter** | Format code with the industry-standard Black formatter |
| 🔍 **Flake8 Linter** | Real-time linting and code quality checks |
| 📄 **Requirements Generator** | Auto-generate `requirements.txt` from your imports |

### ▶️ Execution & Runtime
| Feature | Description |
|---------|-------------|
| 🖥️ **GUI Auto-Detection** | Automatically detects Tkinter/PyQt/Pygame/Kivy and runs without console |
| 💻 **Terminal Mode** | Non-GUI scripts launch in a dedicated terminal window |
| 🖥️ **Built-in Terminal** | Integrated terminal emulator for quick commands |
| 🏃 **F5 Run** | Instant execution with environment-aware Python interpreter detection |

### 🛠️ Build & Distribution
| Feature | Description |

### 🕵️ Reverse Engineering

## 🚀 Installation

### Prerequisites
- Python **3.8+**
- `pip` package manager

### Clone & Run
```bash
# Clone the repository
git clone https://github.com/yourusername/python-idle-pro.git
cd python-idle-pro

# Install dependencies
pip install customtkinter jedi

# Optional: For full feature support
pip install black flake8 pyarmor pyinstaller

# Launch the IDE
python python.py
```

### Windows Standalone
```bash
# Build your own executable
python -m pyinstaller --onefile --noconsole --name "PythonIDLEPro" python.py
```

## 🎮 Usage

### Quick Start
1. **New File**: `Ctrl+N` or click 📄 New
2. **Open File**: `Ctrl+O` or click 📂 Open
3. **Save**: `Ctrl+S` or click 💾 Save
4. **Run**: `F5` or click ▶️ Run

### Building an EXE
1. Open your Python script
2. Click **🔍 Analyze** to detect dependencies
3. Check desired build options (`--onefile`, `--noconsole`, etc.)
4. (Optional) Enable **🔐 PyArmor** encryption
5. Click **⚡ Build EXE**
6. Find your executable in the `dist/` folder

### Reverse Engineering an EXE
1. Click **📦 Extract EXE** section
2. Click **🔍 Extract .pyc** and select a PyInstaller `.exe`
3. The main `.pyc` file is extracted and copied next to the original EXE
4. Click **🌐 pylingual.io** to decompile online

## 🏗️ Architecture

```
python-idle-pro/
├── python.py              # Main application entry point
├── .pymanager_config.json # User preferences (auto-generated)
├── dist/                  # Built executables output
└── temp_extract_*/        # Temporary extraction folders (auto-cleaned)
```

### Tech Stack
- **GUI Framework**: [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) — Modern, customizable Tkinter widgets
- **Code Analysis**: `ast` (Abstract Syntax Tree) — Zero-dependency parsing
- **Auto-Completion**: [Jedi](https://jedi.readthedocs.io) — Static analysis for Python
- **Formatting**: [Black](https://black.readthedocs.io) — The uncompromising code formatter
- **Linting**: [Flake8](https://flake8.pycqa.org) — Style guide enforcement
- **Build Tool**: [PyInstaller](https://pyinstaller.org) — Bundles Python into executables
- **Encryption**: [PyArmor](https://github.com/dashingsoft/pyarmor) — Obfuscate and encrypt Python scripts
